# Microsoft Store packaging

The app uses Win32 and can be packaged as an x64 full-trust desktop MSIX. The package declares `runFullTrust` because it searches user-selected filesystem locations with the user's existing permissions. It runs as a normal user and does not require elevation.

## Package

1. Reserve the final product name in your Microsoft Partner Center account. Copy the **Package/Identity/Name**, **Package/Identity/Publisher**, and **Publisher display name** from the product's identity page.
2. Install the Windows SDK with MSIX packaging tools. Build the executable with `build.ps1`.
3. Run, substituting your exact registered identity values:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\packaging\Build-MSIX.ps1 `
  -IdentityName 'YOUR-PARTNER-CENTER-IDENTITY' `
  -Publisher 'CN=YOUR-PUBLISHER-ID' `
  -PublisherDisplayName 'Your publisher name'
```

The script generates a fresh staging folder, writes XML-escaped identity values, creates logo assets, and calls MakeAppx. Output: `dist/BareClone-1.0.0.0-x64.msix`. It does not install or submit anything.

4. For local sideload testing, sign the package with a certificate whose subject matches Publisher, and trust that certificate on the test machine. Do not ship a private signing key. Store submission uses the reserved Store identity and Microsoft's distribution signing process.
5. Test installation, launch, search, Stop, Unicode filenames, CSV export, upgrade, and uninstall on clean Windows 10/11 x64 machines. Run the Windows App Certification Kit on the final package.
6. Add accurate screenshots, description, support/privacy URLs, age rating, and capability explanation in Partner Center, then submit for review.

No Partner Center identity was supplied, and MakeAppx/Windows App Certification Kit were unavailable here. The MSIX template and packaging script have not been validated by those tools; Store acceptance is not implied.

## Suggested listing text

**BareClone — Native File Search**

Search text across local files and folders. Filter filenames, use regular expressions, preview matching lines, and export results to CSV. Built with native Windows controls, parallel scanning, and a responsive Stop button.

Privacy statement draft: BareClone processes file contents locally. It has no account system, analytics, telemetry, or built-in network requests. It reads folders selected by the user and writes CSV files only when the user chooses Export. Opening files and folders launches Windows applications. Publish this statement at a support URL you control and review it whenever features change.
